.table-edit keeps .table's type and adds a top rule per row, no row hover (the cell is the target, not the row) and right alignment via .num. Cells are .input.cell-input — always live, never behind a click-to-edit: a settings table is edited a column at a time. .is-num fixes the width and right-aligns; .is-empty marks a value that is not loaded rather than zero. tr.is-off is a row kept for its history but withdrawn from new use, and .cell-reason puts the reason an action is unavailable beside the action itself, never in a tooltip.
