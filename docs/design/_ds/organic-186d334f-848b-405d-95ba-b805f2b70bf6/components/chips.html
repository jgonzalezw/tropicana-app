Chips — pick any that apply
With the check glyph

Use .seg when exactly one option can be true — it fills the active option with solid --color-accent. Use .chips / .chip when several can: three solid-accent options inside one container read as a single mass and fight any segmented above them, so the ticked chip is the tinted pill (accent-200 on accent-400) and solid accent stays reserved for one-of-N. The optional .chip-tick glyph appears only when ticked. Chips grow to fit their label and wrap; they are not forced to equal widths.
